# ADR-001: Targeted Bug-Fix Batch Scope for third-fixes

## Status

Accepted

## Date

2026-05-21

## Context

The `third-fixes` release addresses five concrete issues identified in `prompt.md`:
1. CTA button pulse effect clipped by parent overflow
2. Missing favicon configuration
3. Duplicate/unused image cleanup
4. Rafaela bio text update
5. Next.js hydration error from `lang` attribute mismatch

Two broader scope options were also considered: full unused-asset audit (Approach B) and a metadata standards pass (Approach C).

## Decision

Use Approach A — a targeted fix batch. Fix only the five items in `prompt.md`, replace the OG image with `new-hero1.png`, and delete the `fotos/` source directory. No additional asset audit or metadata standards work in this release.

## Alternatives Considered

### Alternative B: Fixes + full asset audit

- **Description**: Remove all unused images (`hero2.png`, `hero3.png`, `rafa.png`) and default Next.js template SVGs from `public/` alongside the five prompt fixes
- **Pros**: Cleaner `public/` folder, reduced repo size
- **Cons**: Slightly larger diff; risk of accidentally removing a file that has a non-obvious reference
- **Why rejected**: Storage impact is low and cleanup can be done independently without time pressure

### Alternative C: Fixes + metadata standards pass

- **Description**: Audit all Open Graph tags, canonical URLs, and meta descriptions to align with current brand
- **Pros**: Complete metadata alignment in one pass
- **Cons**: Requires business input on copy and URLs not covered by the current prompt; significantly expands scope
- **Why rejected**: Out of scope for this iteration; metadata audit is a separate initiative

## Consequences

### Positive

- Minimal diff, easy to review and roll back individual items
- All five user-reported issues resolved in one release
- OG image updated to current hero photography
- `fotos/` directory removed, eliminating confusion about the canonical source of images

### Negative

- `hero2.png`, `hero3.png`, `rafa.png`, and default SVGs remain in `public/images/` as dead assets; requires a future cleanup pass

### Risks

- Removing `fotos/` is irreversible without git recovery — verify no build step references it before deletion
