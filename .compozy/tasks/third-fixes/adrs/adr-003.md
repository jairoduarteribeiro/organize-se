# ADR-003: CTA Button Pulse Visibility Fix Strategy

## Status

Accepted

## Date

2026-05-21

## Context

`CTABlock.tsx` wraps both the countdown grid and the CTA button in a single `div.w-full.overflow-x-clip`. The CTA button carries `animate-scale-pulse`, which scales from 1 to 1.03. Because the button is `w-full`, the 3% horizontal expansion is immediately clipped by the parent's `overflow-x-clip`, making the pulse imperceptible. Three strategies were evaluated to make the animation visible.

## Decision

Remove `overflow-x-clip` from the outer wrapper div and add `px-1` (4px per side) horizontal padding. The `px-1` provides the 1.03× scale room to breathe at the button edges without introducing a horizontal scrollbar on any viewport.

## Alternatives Considered

### Alternative A: Remove overflow-x-clip only

- **Description**: Drop the `overflow-x-clip` class with no other changes
- **Pros**: Minimal diff — single class removal
- **Cons**: The button still spans the full container width; at the edges the 3% expansion may still be invisible or extremely tight on narrow viewports (320–375px)
- **Why rejected**: `px-1` costs nothing and guarantees visible edge expansion regardless of parent container width

### Alternative B: Nested div with overflow-x-visible

- **Description**: Keep `overflow-x-clip` on the outer container but wrap only the animated `<a>` in a new inner `div` with `overflow-x-visible`
- **Pros**: Preserves the existing overflow containment for the countdown grid
- **Cons**: Adds a DOM node; `overflow-x-visible` on a child of `overflow-x-clip` parent is overridden by the parent in most browsers — the fix would not work
- **Why rejected**: Browser overflow model makes nested visible/clip combination unreliable; the countdown grid does not need overflow protection anyway

## Consequences

### Positive

- Scale pulse is visible at all viewport widths (verified at 320px, 375px, 768px, 1280px)
- No additional DOM nodes
- `prefers-reduced-motion` suppression in `globals.css` is unaffected

### Negative

- The outer wrapper loses its horizontal overflow guard; if a future child element overflows, it will be visible rather than clipped

### Risks

- On very narrow viewports (320px), `px-1` reduces button horizontal padding by 4px total — negligible given the button's existing `px-6`
