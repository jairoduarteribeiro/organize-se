# ADR-005: Native <details>/<summary> for FAQ Accordion

## Status

Accepted

## Date

2026-05-19

## Context

The PRD requires an accordion-style FAQ with 5 items that are keyboard-navigable and expand on click/tap. Three implementations were evaluated: native HTML `<details>/<summary>`, a `useState`-controlled React component, and Radix UI Accordion.

## Decision

Use native HTML `<details>` and `<summary>` elements with CSS `max-height` transition for smooth open/close animation. No JavaScript is required. The element is keyboard-navigable by default (Space/Enter toggles, Tab navigates). A CSS `details[open] > .answer` selector drives the reveal animation.

## Alternatives Considered

### Alternative B: Controlled React State

- **Description**: `useState<number | null>` tracks the open item; clicking toggles it
- **Pros**: Full control over animation; easy to enforce single-open behaviour
- **Cons**: Requires `"use client"` on the FAQ component; more code for the same user outcome
- **Why rejected**: `<details>` achieves the same outcome with less code and no client JS

### Alternative C: Radix UI Accordion

- **Description**: Add `@radix-ui/react-accordion` for full ARIA compliance
- **Pros**: Battle-tested accessibility; animation variants built in
- **Cons**: Adds a dependency for a pattern the browser handles natively
- **Why rejected**: `<details>/<summary>` is ARIA-compliant by spec; the added dependency weight is not justified

## Consequences

### Positive

- Zero new dependencies
- FAQ section is a pure Server Component (no `"use client"`)
- Native `<details>` open/close state is preserved across page navigations
- Browser handles focus management and ARIA roles automatically

### Negative

- `<details>` allows all items to be open simultaneously (not exclusive) — acceptable for this FAQ use case
- CSS `max-height` transition requires setting an explicit `max-height` value for the open state

### Risks

- Safari adds a disclosure triangle marker by default — suppressed with `summary { list-style: none }` and `summary::-webkit-details-marker { display: none }`

## Implementation Notes

- Each FAQ item: `<details class="..."><summary class="...">Question</summary><div class="answer ...">Answer</div></details>`
- Animation: `details .answer { max-height: 0; overflow: hidden; transition: max-height 300ms ease }` and `details[open] .answer { max-height: 500px }`
- Custom chevron icon rotates on open via `details[open] summary .chevron { transform: rotate(180deg) }`
