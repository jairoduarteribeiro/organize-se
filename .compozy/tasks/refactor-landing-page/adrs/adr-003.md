# ADR-003: Install lucide-react for Instagram icon

## Status

Accepted

## Date

2026-05-20

## Context

PRD F8 requires a monochrome Instagram icon in `BioSection.tsx` next to Rafaela's handle. The PRD states: "Use Lucide React's `Instagram` icon if available; otherwise inline a monochrome SVG." Lucide React is not currently in `package.json`. The PRD explicitly permits adding it as an exception when it is not already installed.

## Decision

Install `lucide-react` as a production dependency via `bun add lucide-react`. Use the `<Instagram />` component from Lucide in `BioSection.tsx`, rendered with `aria-hidden="true"` and explicit `size` / `strokeWidth` props.

## Alternatives Considered

### Alternative 1: Inline SVG

- **Description**: Copy a monochrome Instagram SVG path string directly into `BioSection.tsx` as a `<svg>` element.
- **Pros**: Zero new dependencies; no bundle size increase beyond the inlined bytes.
- **Cons**: SVG markup is opaque and must be maintained manually; no type safety; inconsistent with how icons would be handled if the project adds more icons later.
- **Why rejected**: The PRD explicitly permits installing Lucide React for this case, and the library provides a consistent, tree-shakeable icon API that adds negligible bundle weight when used correctly.

## Consequences

### Positive

- Consistent icon API available for future icon needs across the landing page.
- Tree-shakeable import — only the `Instagram` SVG is included in the bundle.
- Type-safe props (`size`, `strokeWidth`, `color`) instead of raw SVG attributes.

### Negative

- One new production dependency added to the project.

### Risks

- None significant. Lucide React is a stable, widely-used library with no transitive dependencies.

## Implementation Notes

```tsx
import { Instagram } from "lucide-react";

// Inside BioSection button:
<Instagram size={18} strokeWidth={1.75} aria-hidden="true" />
```

The icon must be `aria-hidden="true"` because the button text already describes the destination (`@rafaelaribeirofinancas`).
