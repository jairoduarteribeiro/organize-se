# ADR-003: Instagram Icon Color Treatment

- **Status**: Superseded by ADR-005
- **Date**: 2026-05-21

## Context

The Instagram icon in BioSection currently renders in a flat color. The requirement is the official Instagram brand gradient (pink → purple).

## Decision

Apply Instagram's official brand gradient (`#E1306C` → `#833AB4`) via an inline SVG gradient definition or a CSS `background-clip: text` + gradient technique wrapped inside a styled container.

## Alternatives Considered

| Approach | Trade-offs |
|----------|-----------|
| **Flat brand purple (#833AB4)** | Simpler but deviates from the "official color" requirement |
| **PNG/SVG asset** | Pixel-perfect but requires an extra asset file and breaks the `lucide-react` icon system |

## Consequences

- Lucide icons render as `<svg>` elements; a wrapping `<span>` with a CSS gradient mask (`background: linear-gradient; background-clip: text; -webkit-text-fill-color: transparent`) applied to the SVG `fill` achieves the effect.
- No additional asset files needed.
