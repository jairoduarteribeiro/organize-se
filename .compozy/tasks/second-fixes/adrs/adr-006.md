# ADR-006: Mobile Hero Layout Correction

- **Status**: Accepted
- **Date**: 2026-05-21

## Context

`HeroSection` uses `flex-col md:flex-col-reverse` on its section element. The DOM order is [text div, images div]. On mobile (`flex-col`), the text renders above the images — contrary to the PRD's requirement of image-first hierarchy on mobile. The md+ breakpoint already shows images first via `flex-col-reverse`.

## Decision

Remove the `md:` breakpoint prefix: change `flex-col md:flex-col-reverse` to `flex-col-reverse` on the section element. This extends the existing desktop behavior (images visually first) to all screen sizes without touching the DOM.

## Alternatives Considered

| Approach | Trade-offs |
|----------|-----------|
| **DOM restructure** (move images div before text div in JSX) | Semantically cleaner source order, but requires adding `lg:order-last` to restore the visual order for desktop if the desktop layout differs — more markup changes for the same visual result |
| **CSS `order` utilities on children** | Equivalent outcome; `order-first` on the images div achieves the same thing as extending `flex-col-reverse`, but requires changes to the child element instead of the parent |

## Consequences

- One class change on `<section>` in `HeroSection.tsx`.
- `flex-col-reverse` on all breakpoints: images div (second in DOM) renders visually first; text div renders below. This matches both the mobile target layout and the pre-existing md+ visual layout.
- No change to DOM order, so screen readers continue to encounter text before images (acceptable — the `<h1>` remains the first heading in document order).
