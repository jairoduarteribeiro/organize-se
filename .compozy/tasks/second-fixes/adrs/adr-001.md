# ADR-001: Testimonials Carousel Library

- **Status**: Accepted
- **Date**: 2026-05-21

## Context

The testimonials section currently renders a static 4-column grid. The requirement is an auto-advancing carousel (10s interval) with arrow navigation on desktop and swipe support on mobile.

## Decision

Use **Embla Carousel** as the carousel library.

## Alternatives Considered

| Library | Trade-offs |
|---------|-----------|
| **Swiper.js** | Feature-rich but heavier bundle (~100 KB); overkill for a simple 4-slide carousel |
| **Custom CSS + hooks** | Zero dependency but requires building touch events, arrow logic, and interval management from scratch — high maintenance surface |

## Consequences

- Add `embla-carousel-react` as a production dependency.
- Lightweight (~10 KB gzipped); no CSS framework conflicts.
- Built-in pointer/touch event handling covers the swipe-on-mobile requirement.
- Auto-advance implemented via `useEffect` interval that calls `emblaApi.scrollNext()`.
